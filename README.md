# 🌸 Iris Flower Classification

This project uses the classic **Iris dataset** to build a machine learning model that classifies flowers into:
- Setosa
- Versicolor
- Virginica

It demonstrates data preprocessing, training a classifier, visualizing results, and plotting a decision boundary.

---

## 📁 Dataset
The Iris dataset is included in `scikit-learn` and contains:
- 150 samples
- 4 features: sepal length, sepal width, petal length, petal width
- 3 target classes

---

## 🔧 Tools Used
- Python
- Google Colab
- Pandas, NumPy
- Seaborn, Matplotlib
- scikit-learn

---

## 📊 Project Steps
1. Load and inspect the dataset
2. Perform exploratory data analysis (EDA)
3. Train/test split
4. Train a **RandomForestClassifier**
5. Evaluate performance with a **classification report**
6. Plot the **decision boundary**

---

## 🚀 Output
Achieved 100% accuracy on test data (small dataset).  
Decision boundaries plotted using the first 2 features for 2D visualization.

---

## 📤 How to Run
1. Clone or download this repo
2. Open `iris_classification.ipynb` in Jupyter or Google Colab
3. Run all cells
